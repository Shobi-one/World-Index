# World Index

RDR2-inspired D&D world index built with plain HTML/CSS/JS and Markdown content.

## Start

1. Install Node.js 18+.
2. Run `npm run build:content` to convert Markdown files in `content/` into JSON files in `data/`.
3. Open `index.html` in a local static server (recommended) or directly in a browser.

## Content Structure

- `content/characters`
- `content/clans`
- `content/towns`
- `content/mesas`
- `content/regions`

Each Markdown file uses simple frontmatter between `---` markers.
